# Baby Steps HTML5

Este proyecto reúne una serie de ejercicios básicos de **HTML5** y **CSS3** enfocados en la estructura semántica, la manipulación de texto, la creación de botones y el uso de listas ordenadas y no ordenadas.

## Objetivo

Practicar los fundamentos de HTML5 mediante la réplica de diferentes maquetas y el uso de etiquetas semánticas, complementando el diseño con estilos básicos en CSS3.

## Tecnologías utilizadas

- HTML5
- CSS3

## Ejercicios realizados

### 1. Manipulación de texto
- Réplica de la página de **Tim Berners-Lee**.
- Uso de etiquetas semánticas como `header`, `main`, `section`, `article` y `footer`.

### 2. Creación de botones
- Botón **Like** 👍
- Botón **Dislike** 👎
- Botón **Salir**, con enlace a la página de Factoria F5.

### 3. Manipulación de listas
- Listas ordenadas (`ol`).
- Listas no ordenadas (`ul`).
- Aplicación de estilos básicos con CSS3.
